

## 🌌 Interactive AR Solar System Project

## 🚀 Project Overview

An engaging Augmented Reality (AR) project that brings the Solar System into the real world using image tracking. When the camera detects the target image, 3D planets appear and animate around the Sun, creating an interactive learning experience.

## 🎥 Project Demo Video

Watch the working demo here: https://youtu.be/xzvtdncIB2Y

## ✨ Core Features

### 📸 Image Tracking

Detects a specific Solar System image and instantly launches the AR scene with planets.

### 🪐 3D Animated Planets

Each planet rotates and moves realistically using animation scripts.

### 📏 Planet Scaling & Positioning

Planets are arranged with proper size and spacing for a realistic AR view.

### 🎨 Realistic Textures

Unique materials and textures are applied to every planet for better visual appeal.

## 🛠️ Technology Used

- Unity 2022.3 (LTS) – Stable game engine for AR development  
- AR Image Target Tracking – For scene activation  
- 3D Models & Materials – Sun and planets with custom textures  
- C# Scripts – Used for rotation and movement effects  

## 🌟 Future Enhancements

- Add planet name labels  
- Speed control slider for orbits  
- Background space sound/music  
- Tap planets for facts or voice narration  

## 🎯 Purpose

To make learning about the Solar System more fun, interactive, and visually immersive through AR technology.
